# Glosarium

Istilah pemrograman dan analisis data yang dipakai di buku ini, beserta padanan bahasa Inggrisnya. Angka di akhir menunjuk bab tempat istilah itu dijelaskan.

| Istilah | Inggris | Arti |
|---|---|---|
| agregasi | aggregation | Meringkas banyak nilai menjadi satu, misalnya jumlah atau rata-rata (15) |
| akumulator | accumulator | Variabel penampung yang diperbarui di setiap putaran (4, 6) |
| argumen | argument | Nilai yang dikirim saat memanggil fungsi (5) |
| asinkron | asynchronous | Pekerjaan yang hasilnya datang belakangan (12) |
| boolean | boolean | Tipe data bernilai `true` atau `false` (2) |
| callback | callback | Fungsi yang dikirim untuk dipanggil nanti, misalnya saat tombol diklik (10) |
| class | class | Cetakan untuk membuat objek sejenis (24) |
| CTE | common table expression | Hasil antara bernama di SQL, ditulis dengan `WITH` (21) |
| CSV | comma-separated values | Teks berisi tabel, kolom dipisah koma (11) |
| DataFrame | DataFrame | Tabel milik Slak Data, gaya pandas (14) |
| deret waktu | time series | Data yang diurutkan menurut waktu (20) |
| destructuring | destructuring | Mengambil beberapa isi objek atau larik sekaligus ke variabel (7) |
| DOM | Document Object Model | Struktur halaman web yang bisa diubah JavaScript (10, 26) |
| fungsi | function | Kumpulan perintah bernama yang bisa dipanggil berulang (5) |
| fungsi panah | arrow function | Cara ringkas menulis fungsi: `x => x * 2` (5) |
| galat | error | Kesalahan yang menghentikan program (9) |
| hipotesis nol | null hypothesis | Anggapan awal "tidak ada perbedaan" dalam uji statistik (19) |
| indeks | index | Posisi isi larik, dimulai dari 0 (6) |
| jalan ulang | rerun | Slak menjalankan ulang seluruh skrip setiap ada interaksi (10) |
| JOIN / gabung | join / merge | Menggabungkan dua tabel lewat kunci (18, 21) |
| JSON | JavaScript Object Notation | Teks berbentuk objek dan larik JavaScript (11) |
| klaster | cluster | Kelompok data yang mirip, ditemukan sendiri oleh model (22) |
| klasifikasi | classification | Menebak kelompok, misalnya churn atau tidak (22) |
| komentar | comment | Teks di kode yang diabaikan komputer, diawali `//` (2) |
| korelasi | correlation | Ukuran seberapa kuat dua variabel bergerak bersama (19) |
| kuartil | quartile | Nilai yang membagi data menjadi empat bagian sama banyak (19) |
| kunci | key | Kolom penghubung dua tabel; juga identitas widget di Slak (10, 18) |
| larik | array | Daftar nilai berurutan (6) |
| machine learning | machine learning | Program yang belajar aturan dari contoh (22) |
| median | median | Nilai tengah data yang diurutkan (5) |
| metode | method | Fungsi milik sebuah objek, misalnya `teks.trim()` (8, 24) |
| modul | module | Berkas JavaScript yang membagikan fungsi dengan `export` (24) |
| modus | mode | Nilai yang paling sering muncul (5) |
| objek | object | Kumpulan pasangan nama dan nilai (7) |
| overfitting | overfitting | Model menghafal data latih sehingga buruk pada data baru (22) |
| p-value | p-value | Peluang melihat hasil sebesar ini bila hipotesis nol benar (19) |
| parameter | parameter | Nama penerima nilai di dalam fungsi (5) |
| pencilan | outlier | Nilai yang jauh berbeda dari kebanyakan data (13, 19) |
| percabangan | branching | Memilih jalan program dengan `if` atau `switch` (3) |
| perulangan | loop | Mengulang perintah dengan `for` atau `while` (4) |
| persentil | percentile | Nilai yang di bawahnya terdapat persen tertentu dari data (19) |
| pratinjau | preview | Bagian yang menampilkan aplikasi yang sedang berjalan (1) |
| Promise | Promise | Janji bahwa hasil akan datang nanti (12) |
| properti | property | Satu pasangan nama dan nilai di dalam objek (7) |
| R² | R-squared | Seberapa banyak naik-turunnya data dijelaskan model, 0 sampai 1 (22) |
| rata-rata bergerak | moving average | Rata-rata beberapa periode terakhir untuk menghaluskan data (20) |
| regex | regular expression | Pola untuk mencari atau mengganti teks (8, 13) |
| regresi | regression | Model untuk menebak angka, misalnya garis tren (22) |
| scope | scope | Wilayah tempat sebuah variabel dikenal (5) |
| Series | Series | Satu kolom DataFrame (14) |
| simpangan baku | standard deviation | Ukuran seberapa jauh nilai menyimpang dari rata-rata (19) |
| spread | spread | Menyalin isi objek atau larik dengan `...` (7) |
| state | state | Nilai yang diingat antar-jalan ulang (10) |
| string / teks | string | Tipe data berisi teks (2) |
| tautan berbagi | share link | Alamat playground yang memuat kode (1) |
| template literal | template literal | Teks bertanda backtick dengan sisipan `${...}` (2) |
| tipe data | data type | Jenis nilai: angka, teks, boolean, dan seterusnya (2) |
| uji A/B | A/B test | Eksperimen membandingkan dua versi secara acak (19) |
| uji otomatis | automated test | Kode yang memeriksa hasil kode lain (9, 24) |
| variabel | variable | Nama untuk menyimpan nilai (2) |
| widget | widget | Kontrol interaktif: tombol, penggeser, kotak isian (3) |
| window function | window function | Fungsi SQL yang menghitung di sekitar setiap baris (21) |
